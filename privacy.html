Privacy Policy — Hootenhollow Publisher

Last updated: October 4, 2026

Hootenhollow Publisher (the "App") is a private tool used only by the owner of the Hootenhollow YouTube channel to upload and manage the channel's own videos. It is not offered to the public.

What data the App accesses

With the channel owner's permission (Google OAuth), the App uses the YouTube Data API to upload videos, set titles, descriptions, tags, thumbnails and playlists, update channel branding and read the channel's own video and statistics data.

How the data is used and stored

  • Data is used only to publish and manage videos on the owner's own channel.
  • The OAuth token is stored only on the owner's computer and is never shared.
  • The App does not collect, sell or share any personal data, and it does not access data of viewers, including children who watch the channel.

Google API Services User Data Policy

The App's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The App uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions: contact the channel owner via the email listed on the Hootenhollow YouTube channel's About page.
